# Milestones

Built one at a time, each proven by its own scenario before the next starts.

| # | Milestone | Status |
|---|---|---|
| 01 | [Tonight's schedule](01-tonights-schedule.md) | proposed |
| 02 | [A question for the current talk](02-a-question-for-the-current-talk.md) | proposed |
| 03 | [The board sorts by votes](03-the-board-sorts-by-votes.md) | proposed |
| 04 | [The lightning list](04-the-lightning-list.md) | proposed |
| 05 | [The organiser runs the night](05-the-organiser-runs-the-night.md) | proposed |
| 06 | [The big screen](06-the-big-screen.md) | proposed |
| 07 | [The room scans in](07-the-room-scans-in.md) | proposed |

The order is not negotiable in one place: **05 must come before 06**, because the
big screen shows the top questions *for the current talk*, and until an organiser
can move the current talk there is nothing to prove.

<!-- pikku:knowledge-index -->
- [Tonight's schedule, with what is on now at the top](01-tonights-schedule.md) — The spine — the running order exists, one slot is current, and the room can see which.
- [A question for the current talk](02-a-question-for-the-current-talk.md) — The main thing someone does on their first visit — type your name once, ask the speaker something.
- [The board sorts by votes](03-the-board-sorts-by-votes.md) — Upvoting, once per person, and the queue that comes out of it.
- [The lightning list](04-the-lightning-list.md) — A sign-up sheet on a wall. Anyone adds themselves; you may withdraw your own.
- [The organiser runs the night](05-the-organiser-runs-the-night.md) — The passcode, advancing the schedule, and marking a question answered — plus the refusal that proves the gate.
- [The big screen](06-the-big-screen.md) — The projected view — the top three questions for the current talk, in huge type.
- [The room scans in](07-the-room-scans-in.md) — A projected QR code so nobody has to type a URL in a dark room.
