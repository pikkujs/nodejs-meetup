# The Q&A board follows the current talk

There is one Q&A board. It shows the questions for whichever talk is current, and
posting a question attaches it to that talk. When the organiser advances, the
board changes underneath everyone.

## Why

The alternative shapes are both worse in a room:

- **One board for the night** — questions for talk one sit above talk two's for
  the rest of the evening, because they have had 40 more minutes to collect votes.
  The board becomes a history of the evening instead of a queue for right now.
- **A board per talk, with a picker** — a tab bar on a phone, in a dark room,
  where the only tab anyone wants is the one that is on. Every tap is a chance to
  post into the wrong one.

Following the current talk means the board is always the board you want, with no
navigation at all.

## What this rules out

- You cannot ask a question about a talk that has finished. That is deliberate:
  by then the speaker is sitting down and the room has moved on.
- **An interlude has no board.** During doors, the break and pizza the Q&A screen
  says what is happening and offers no composer — a question posted "about pizza"
  is a question that lands nowhere when the next talk starts.
