# Entities

Four things, and nothing else exists in this app.

- [Talk](talk.md) — a slot on tonight's running order
- [Question](question.md) — something someone in the room wants asked
- [Lightning slot](lightning-slot.md) — a name on the 20:20 list
- [Attendee](attendee.md) — a person in the room, who never signs in

<!-- pikku:knowledge-index -->
- [Attendee](attendee.md) — A person in the room. Never signs in — a name typed once, and a browser that remembers it.
- [Lightning slot](lightning-slot.md) — A name on the 20:20 list. Anyone may add themselves; the list is the sign-up.
- [Question](question.md) — Something someone in the room wants asked, attached to the talk that was on when they asked it.
- [Talk](talk.md) — One slot on tonight's running order — including the ones nobody speaks at.
